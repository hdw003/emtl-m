## 边界

实测带锁每日脚本可重跑。真实财务的首次已知日是2026-10-28，而已下载的日线截至10-27，
因此这段真实账本是680个空仓交易日、零成交，`value_status.coverage=none`。
这验证了阻止财务倒填的行为，**不能据此声称价值策略历史收益已验证**。
多年价值回测需导入有时点保证、覆盖退市样本及历史状态的财务数据；合成数据收益不作投资证据。

没有执行真实账户登录、账户查询或下单；没有安装系统cron或部署持续在线主机。
远端Python 3.13 CI结果尚未观察。外部公开财务和价格数据没有逐笔核对发行人公告，
公司行动、每股口径和历史证券状态仍需数据治理。
